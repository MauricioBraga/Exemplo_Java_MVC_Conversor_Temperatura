## Projeto Conversor de Temperatura

Este é um exemplo didático simples de uma aplicação Java com Swing que demonstra o uso do padrão MVC (Model-View-Controller) para converter temperaturas entre Celsius, Fahrenheit e Kelvin. 

## Como clonar e executar

1. Abra um terminal e execute o comando para clonar o repositório:
   ```bash
   git clone <URL_DO_REPOSITORIO> Exemplo_MVC_Conversor_Temperatura
   ```
2. Entre no diretório do projeto:
   ```bash
   cd Exemplo_MVC_Conversor_Temperatura
   ```
3. Compile o código fonte:
   ```bash
   javac -d bin -sourcepath src src/br/com/exemploMVC/Main.java
   ```
4. Execute a aplicação:
   ```bash
   java -cp bin br.com.exemploMVC.Main
   ```

> Observação: Essa é uma aplicação Java, então é necessário ter o JDK instalado e a variável `JAVA_HOME` configurada para compilar e executar o projeto.
